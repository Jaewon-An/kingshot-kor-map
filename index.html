✏ 도구 및 편집

🛠배치 / 선택 / 지우기 — 툴바에서 고르거나 D / S / E 키를 누르세요.
🖱선택 또는 지우기 모드에서 우클릭하면 건물 하나를 지웁니다. 도구를 바꿀 필요가 없습니다.
▭사각형 지우기 — 지우기 모드에서 우클릭으로 영역을 지정한 뒤, 다시 우클릭하면 삭제가 확정됩니다.
☑다중 선택 — 선택 모드에서 빈 곳을 Shift+드래그하면 여러 건물을 한꺼번에 선택합니다. 선택된 그룹을 드래그하면 한 묶음으로 일괄 이동합니다.
✏선택한 건물을 더블클릭하면 이름을 바꿀 수 있습니다.
📋Ctrl+C로 선택한 건물을 복사하고, Ctrl+V로 같은 이름·색상의 사본을 배치합니다.
↩Ctrl+Z 되돌리기 · Ctrl+Y(또는 Ctrl+Shift+Z) 다시 실행.

🏰 연맹 깃발 및 영토

⚠깃발과 본부의 이름에는 3글자 연맹 태그를 사용하세요(예: PHZ). 영토는 이름 기준으로 합쳐집니다 — 같은 이름 = 같은 영토.
🔢배치 순서가 중요합니다 — 게임과 마찬가지로 영토가 겹치는 곳에서는 먼저 배치한 깃발과 본부가 우선합니다.
🔴빨간 ✕ 표시된 도시는 모든 연맹 영토 밖에 있어 연맹 보너스를 받지 못합니다.
📏연맹당 한도: 깃발 285개, 본부 2개. 배치 경고를 무시할 수는 있지만, 게임에서는 이 한도를 넘는 것은 인정되지 않습니다.
📊툴바에서 연맹 요약을 열면 수량(본부 · 깃발 · 도시), 검증 경고, 시간당 자원 생산량, 구역별 영토를 볼 수 있습니다. 각 행에는 소유 기준 도시 수(4칸 중 3칸 이상이 연맹 영토 안)도 표시됩니다.
🪖각 요약 행에는 버튼이 두 개 있습니다. 하이브 계획(연맹 도시가 10개 이상 모여 있을 때만 표시)은 격리된 하이브 보기를 열고, 도시 내보내기는 해당 연맹 영토로 한정된 도시 내보내기 창을 엽니다. 자세한 내용은 하이브 보기 탭을 참고하세요.
🌾자원지 (빵/고기 · 목재 · 석재/석탄 · 철광)는 고정되어 있으며 게임 내 지도와 일치합니다. 위치가 틀렸다면 자원지를 선택하고 📝 오류 신고를 클릭하세요(클라우드에 게시된 지도 필요).

🪖 하이브 보기

👀연맹 격리 보기 — 다른 연맹의 건물을 모두 숨기고 한 연맹의 하이브(본부 + 깃발 + 도시 + 곰 함정)만 보여줍니다. 깔끔한 화면을 공유하거나 적 하이브를 정찰할 때 유용합니다.
▶연맹 요약에서 열 수 있습니다. 도시가 10개 이상 모여 있는 연맹 행에 하이브 계획 버튼이 나타납니다.
🔗직접 링크 공유: 보기 화면의 🔗 링크 복사 버튼을 사용하세요. 받는 사람은 같은 하이브 보기로 바로 열립니다.
🏙🏙 도시 내보내기(상단 바)는 이 하이브만 대상으로 도시 내보내기를 엽니다. 멤버에게 이주 메시지를 보낼 때 편리합니다.
🖱좌클릭 드래그로 이동, 마우스 휠로 확대/축소합니다. 하이브 보기는 읽기 전용입니다. Esc를 누르면 나갑니다.

⚡ 깃발 최적화

🚀툴바의 ⚡ 깃발 최적화 버튼으로 엽니다. 본부와 여러 전초기지를 연결하는 데 필요한 최소 깃발 수를 찾아줍니다.
1️⃣1단계 — 시작 지점: 지도를 클릭하거나 연맹 드롭다운에서 본부 또는 기존 깃발을 선택합니다.
2️⃣2단계 — 목표 전초기지: 점령할 전초기지를 선택합니다(건설, 방어, 연구, 개척자 오두막 등). 가장 가까운 곳 자동 선택을 체크하면 종류별로 가장 가까운 곳을 자동으로 고릅니다.
3️⃣3단계 — 옵션: 같은 연맹만은 결과를 한 연맹의 영토 안으로 제한합니다. 자원지 확보는 근처 자원도 함께 연결합니다.
▶실행을 눌러 계산합니다. 이전 / 다음으로 다른 결과를 살펴본 뒤 적용을 눌러 지도에 깃발을 배치하세요.

🏙️ 하이브 최적화

🚀사이드바의 🏙️ 하이브 최적화 버튼으로 엽니다. 곰 함정까지의 행군 시간이 최소가 되도록 연맹 영토 안에 도시를 자동 배치합니다.
⚠실행 전: 연맹의 본부와 곰 함정 1개 이상이 지도에 있어야 합니다. 최적화는 도시만 배치하며 깃발, 본부, 곰 함정은 배치하지 않습니다.
▶연맹을 고르고 도시 수(1–100)를 입력한 뒤 ▶ 최적화 실행을 클릭하세요. 지도가 격리된 하이브 보기로 전환되고 도시 미리보기가 표시됩니다.
🎨미리보기: 진한 주황색 도시는 B1, 옅은 주황색 도시는 B2로 집결합니다(선택된 함정은 금색 테두리). ◀ ▶로 변형을 비교하세요 — 최단(총 행군 시간 최소)과 균형(두 함정에 고르게 분배).
🔢미리보기에서 배치할 도시 수를 바꾸면 즉시 다시 계산합니다. 들어갈 수 있는 수보다 많이 요청하면 가능한 최대치를 제안합니다.
✓적용하면 도시가 배치되고(이름: [TAG] N) 종료됩니다. ✕는 아무것도 배치하지 않고 취소합니다.

📐 하이브 템플릿

🏗찾아보기 및 찍기 (🏗 버튼): 정렬(인기순 / 최신순), 함정 수, 도시 수로 템플릿을 필터링합니다. 템플릿을 클릭해 선택한 뒤 지도를 클릭하면 찍힙니다.
🔄찍는 중: Q 왼쪽 회전 · E 오른쪽 회전 · X X축 반전 · Y Y축 반전 · Esc 취소. 클릭하면 확정되며, 기존 건물을 덮어쓰기 전에 확인을 요청합니다.
📐만들기 (📐 버튼): 기준점이 있는 99×99 격자 편집기를 엽니다. 도구 팔레트를 사용하거나 숫자 키 1–4로 도시, 깃발, 본부, 곰 함정, 지우기, 이동 도구를 전환합니다.
🧭편집기에서 휠 클릭 또는 Alt+드래그로 이동, 스크롤로 확대/축소합니다. 검증 규칙: 템플릿당 곰 함정 최대 2개, 본부 최대 1개, 도시 최대 100개.
📤이름과 설명을 입력해 저장한 뒤 승인을 요청하세요. 승인된 템플릿은 모든 사용자의 선택 목록에 표시됩니다.
