# kingshot-kor-map

[Kingshot Mapper](https://ksmapper.pages.dev)의 정적 사본에 왕국 #2382 연맹 깃발 배치를 기본 레이아웃으로 넣은 버전입니다. 킹샷 전용입니다(화이트아웃 서바이벌 모드는 제거했습니다).

## 실행

정적 파일이므로 아무 웹 서버로 열면 됩니다.

```sh
python -m http.server 8000
# http://localhost:8000/
```

## 지도 조작

- 빈 곳을 좌클릭 드래그하면 지도가 이동합니다. 휠 클릭 드래그나 Alt+드래그도 됩니다.
- 움직이지 않고 클릭하면 현재 도구의 동작(배치·지우기·선택 해제)을 합니다.
- 선택 도구에서 건물을 드래그하면 건물이 옮겨집니다. 여러 건물을 고르려면 Shift+드래그를 쓰세요.

## 기본 배치 (`kor-layout.js`)

- KOR 금색: 게임 좌표로 확인된 본진 깃발 22개
- KOR 하늘색: 스크린샷의 KOR 영토를 7×7 단위로 분해해 추정한 깃발 235개
- 다른 연맹: 스크린샷 9장(2026-09-29)에서 추정한 본부 20개와 깃발 577개. 연맹마다 게임 속 영토 색에 가까운 색을 지정했습니다.
  본부가 화면 밖에 있어 소속을 알 수 없는 영토는 `미확인(색)`으로 표시합니다. 위치 오차는 약 ±4칸입니다.

브라우저에 저장된 작업본이 없거나 `meta.version`이 바뀌면 기본 배치를 자동으로 불러옵니다.
이전 작업본은 되돌리기(Ctrl+Z)로 복원할 수 있고, `?kor=reset`을 붙이면 언제든 다시 불러옵니다.
본부가 지도에 없는 연맹의 깃발에는 고립(점선) 경고를 표시하지 않습니다.

배치 데이터는 `../tools/territory/`의 스크립트로 다시 만들 수 있습니다.
